# Backend capstone-project
Coursera Back end capstone project for Little Lemon

## 🚀 URL's

- To get to Homepage - restaurant/
- To access menu items - restaurant/menu/
- To access a single menu item - restaurant/menu/<id>
- To make a Reservation - restaurant/booking/tables
- To obtain Authentication token in insomnia - restaurant/api-token-auth/
- For Authentication/Register - auth/users/
- PORT: 8000

Menu and booking view can be reached also through navbar

- Do make sure the format for datetime is as so for BookingDate to make a reservation in insomnia is -  "2025-05-11T18:30:00"
